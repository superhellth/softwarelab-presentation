Challenges

  • No AR-capable phone
  • Building components without knowing the big picture
  • HTML vs. Canvas Text
  • Integrating third-party services (DropBox, OneDrive)

Enablers

  • Solid shared contract saved LOTS of time
  • Conventional Commits, Feature branches
  • Stay up-to-date with upstream
  • Skills
    /grill-me, /superpowers, /impeccable, /improve-codebase-architecture, /caveman
  • GitHub Pages Deployment

What did we achieve?

  • AR tour guide: author a tour, share it via QR code, walk it in AR
  • Agent-guided, test-driven workflow with replayed real walks as e2e tests
  • Ten isolated components around one shared tour contract
